Overview

This project involved designing and building a mobile robot inspired by PAC-MAN. The robot was developed to navigate its environment, search for game objects, and collect them using a scoop mechanism.

My Contribution

I served as the design lead and designed the robot's outer shell. I focused on making sure the shell dimensions could accommodate the internal components while staying within the required 5 × 5 × 5 inch box constraint.

Technical Features

The system included object detection, rotational searching, directional movement, a scoop mechanism, and hand-guided navigation.
