# Teresa Tran — Engineering Portfolio

A clean, responsive portfolio website designed for GitHub Pages.

## Files

- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and footer year
- `images/` — put project photos here

## Put it on GitHub Pages

1. Create a new GitHub repository. For a personal site, `YOUR_USERNAME.github.io` is the standard repository name.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open the repository's **Settings → Pages**.
4. Under the deployment/build section, choose the `main` branch and the root (`/`) folder.
5. Save and wait for GitHub Pages to publish the site.

## Personalize it

Search `YOUR_EMAIL@example.com` and `YOUR_USERNAME` in `index.html` and replace them.

To add a project image, put the image in `images/` and replace a placeholder such as:

`<div class="project-image placeholder">ROBOTICS</div>`

with:

`<img class="project-image" src="images/pacman-robot.jpg" alt="PAC-MAN autonomous robot">`

You can also add individual GitHub/demo buttons inside each project card.
